התקנת אפליקציה (PWA) — Demo

מסך Install שמסביר ל‑Android ול‑iOS + הדמיית התקנה עם “קבצים עוברים” ושעון רץ.

איך מתקינים

Android (Chrome / Edge) 1) פתח את האתר בדפדפן.
2) לחץ תפריט ⋮ ואז Install app / Add to Home screen.
3) אם קופץ חלון התקנה — פשוט אשר.
iOS (Safari) ב‑iPhone/iPad אי‑אפשר להקפיץ “Install Prompt” כמו באנדרואיד — זה ידני:
1) פתח ב‑Safari (לא בתוך אפליקציות כמו Instagram).
2) לחץ כפתור שיתוף ⬆︎
3) בחר Add to Home Screen ואז Add.
הערה: ההדמיה רצה בכל מקרה. באנדרואיד/דסקטופ—אם הדפדפן מאפשר, תופיע גם בקשת התקנה אמיתית בסוף.
