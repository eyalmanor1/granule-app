Overview

This application configures and operates the granules inspection workflow (Granules, Analysis, Calibration, Tools).

Tabs

  • Granules — Define valid/defect colors used by the detection pipeline.
  • Analysis — Preview and validate behavior (simulation / deltas).
  • Calibration — Exposure/brightness reference and tuning utilities.
  • Tools — Operational tools (Camera, Upload, Manuals, Saved, QA, Factory Live).

Recommended first-time workflow

  1. Set Valid and Defect colors in Granules.
  2. Validate behavior in Analysis.
  3. Stabilize brightness/exposure in Calibration.
  4. Use Tools for operation and QA.

Important

  • Some modules initialize only when their accordion/tool is opened (on-demand).
  • After any change, validate in Analysis/QA before production use.
