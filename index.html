Install

Android / Desktop (Chrome, Edge) Tap Install. If eligible, the official browser install prompt will appear.
If not: browser menu ⋮ → Install app / Add to Home screen.
iOS (Safari) iOS requires manual install: Safari → Share ⬆︎ → Add to Home Screen → Add.
Important: websites cannot force-install or force-close the browser. Real install requires the official prompt (Android/Desktop) or “Add to Home Screen” (iOS).
