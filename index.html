Topics
Navigation

Navigation model

The app is organized into bottom tabs (Calibration / Samples / Analyze / Factory / Setup). Each tab keeps its own state, so you can switch between workflows without losing what you were doing.

Best practice

  • Start with Calibration at the beginning of a shift, after any hardware change, or after any lighting change.
  • Use Samples to capture representative images under production conditions.
  • Use Analyze for comparisons, thresholds, trends, and QA decisions.
  • Use Factory for locked-down, repeatable production flow.

Common issues

  • If you see inconsistent results, confirm you are using the correct calibrated profile.
  • If values drift over time, check lighting stability and camera thermal stabilization.

Tip: Treat the bottom tabs as workspaces. Do not “reset” unless you are sure you want to lose context.

Calibration
Calibration contains measurement tools (Lux, CCT, Flicker). Use Capture to take a reading, and Save to store results.
  • If camera view is black: check permissions and close other camera apps.
  • For stable values: keep distance and lock exposure if available.
Samples

Purpose

Samples is where you collect the visual evidence used by Analyze and Factory decisions. A “good sample” must represent real production conditions.

Sources

  • Live camera: best for real-time tuning.
  • Upload: useful for offline analysis, training, and regression testing.

Sampling best practices

  • Capture multiple samples across normal variation (different lots, operators, times of day).
  • Keep geometry consistent: distance, angle, and placement should match production.
  • Label samples with context (line, station, material, batch) when applicable.

What to check

  • Focus and sharpness: blurred samples can fake “smoothness”.
  • Glare: specular highlights can break thresholds.
  • Background: keep it consistent to avoid contamination of ROI statistics.
Analyze

Purpose

Analyze helps you compare samples, compute metrics, and decide pass/fail using repeatable thresholds. It is intended for engineering, QA, and advanced operators.

Recommended workflow

  1. Confirm calibration is valid for the current environment.
  2. Select the right sample set (representative and properly labeled).
  3. Choose ROI and metrics that reflect real quality criteria.
  4. Validate thresholds on a mixed set of good and bad samples.

Interpreting results

  • Use trends to identify drift early.
  • Use comparisons to confirm changes after maintenance or material switch.
  • Export results when you need traceability and reporting.

Common pitfalls

  • Overfitting thresholds to a small sample set.
  • Ignoring lighting changes and assuming the model is “wrong”.
  • Using non-representative samples (clean lab vs factory floor).
Factory

Purpose

Factory mode is optimized for production: minimal steps, repeatability, and reduced risk of operator misconfiguration.

Operational rules

  • Lock configuration after validation.
  • Use clear pass/fail indications.
  • Collect minimal but sufficient traceability data.

Shift-start checklist

  • Clean lens and verify fixture integrity.
  • Run quick calibration validation.
  • Confirm sample capture and analyze path are correct.

If something looks wrong

  • Re-check calibration first.
  • Verify lighting and camera positioning.
  • Use the Version page to copy diagnostics and send to support.
Troubleshooting
  • If nothing clicks: refresh the page. A JS error can stop interactions.
  • If UI is blank: verify the file loaded fully and try opening in Chrome (not a file viewer).
  • If text looks misaligned in RTL: switch language again to re-apply direction.
