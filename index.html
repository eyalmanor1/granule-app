How to install

Android / Desktop (Chrome, Edge) Tap Install below. If your browser supports it, a real install prompt will appear.
If you don’t see a prompt: menu ⋮ → Install app / Add to Home screen.
iOS (Safari) iOS does not allow an automatic install prompt.
Open in Safari → Share ⬆︎ → Add to Home Screen → Add.
Note: the animation is visual, but the install itself is REAL only when your browser shows the official install prompt (Android/Desktop) or you use iOS “Add to Home Screen”.
