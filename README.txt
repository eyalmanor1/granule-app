Vision System Autopilot (PWA)
============================

How to run (IMPORTANT):
- You must serve these files over HTTPS or localhost (service workers do not work via file://).

Quick start options:
1) Python (recommended):
   python -m http.server 8080
   Then open:
   http://localhost:8080

2) Node:
   npx http-server -p 8080

Install:
- Open the site in Chrome/Edge.
- Use the in-app Install (system) button when it appears, or browser install menu.
- After the fake installation finishes, click Continue and preferably launch from the desktop/home icon.
